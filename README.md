# Interest Studio

Compare simple vs yearly compound interest, with a live chart and inflation-adjusted values.

**Live demo:** https://interest-studio.ai.studio

## Features

- Simple vs compound interest over 1 to 30 years, with the difference in ₹ and %
- Live canvas growth chart
- Interest calculator and goal tabs
- Optional inflation adjustment
- Indian currency formatting, dark mode, mobile friendly

## Quick check

₹10,000 at 10% for 3 years: simple ₹13,000.00, compound ₹13,310.00.

## Tech

Plain HTML, CSS and JavaScript. No libraries.

## Run locally

Open `index.html` in your browser.

Built entirely with AI prompts using Google AI Studio.
